# `utils/`

General-purpose utility types and error handling helpers.

## Purpose

Shared TypeScript utilities and Stellar/Soroban type definitions consumed
by multiple backend modules.

## Key Files

| File                | Role                                    |
| ------------------- | --------------------------------------- |
| `error.ts`          | Custom error classes and error helpers  |
| `soroban-types.ts`  | Stellar Soroban SDK type definitions    |
